## 为什么突然想写博客

一直以来，读过的东西都散落在收藏夹、微信文件传输助手、还有各种莫名其妙的临时文档里。过三个月回头找，基本等于丢了。

所以想要一个地方：

- 把**读完一篇论文之后的思考**留下来，而不只是收藏链接；
- 把**工作里踩过的坑**写下来，下次别踩第二遍；
- 偶尔写点跟工作无关的东西，证明自己还活着。

## 这套博客是怎么运转的

整个站点只有三个部分：

1. `content/posts/` 里放 Markdown 文件 —— 一篇文章就是一个 `.md`；
2. 一条命令 `node build.mjs`，把 Markdown 编译成静态网页，输出到 `dist/`；
3. 把 `dist/` 整个扔到任何静态托管（GitHub Pages / Netlify）上，就上线了。

没有数据库，没有后台，不需要服务器。文章本质上是**纯文本文件**，二十年后的软件大概都还读得懂。

## 写一篇新文章有多麻烦

不麻烦，三步：

```bash
# 1. 新建一个文件，文件名就是网址
#    content/posts/2026-11-01-my-first-post.md

# 2. 写上开头这几行（frontmatter）
#    ---
#    title: 标题
#    date: 2026-11-01
#    category: work
#    tags: [标签1, 标签2]
#    summary: 一句话摘要，会显示在列表里
#    ---

# 3. 重新构建
node build.mjs
```

就这些。剩下的排版、目录、标签页、RSS、搜索，构建脚本会自己搞定。

## 一点私心

我挺喜欢这种「内容就是文件」的感觉。它不会因为我换了一台电脑、换了一个平台、或者某个服务停止运营而消失。

写下来，就算数。
